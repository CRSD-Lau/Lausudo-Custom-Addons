# Client enhancements

Author: Neil Mitchell

Lausudo Suite covers the addon layer now and provides a place to document compatible client enhancements as they are reviewed. Its public addon ZIP does not include a complete game client.

| Area | Public suite treatment today |
| --- | --- |
| WoW executable and base data | Bring your own compatible 3.3.5a installation. Not packaged here. |
| HD model/effect MPQs | No automated download or installation; future entries need exact version/hash, provenance, dependencies, and in-game evidence. |
| Graphics wrappers and ReShade | Not bundled or modified. Use the component's trusted distribution and license. |
| Private fonts, shaders, LUTs | No copying from the owner's client. Use permitted alternatives where available. |
| Driver / Process Lasso / Windows settings | Outside the addon package and outside client-folder recovery. |

Client enhancement recipes should record what the user gets, supported client build, source, license, installation location, rollback, and known conflicts. A file's presence in a working private client is not enough evidence to add it to a public download.

No exact HD/client enhancement set has been certified by this suite preview. Avoid treating an addon package verification as a graphics compatibility test.
