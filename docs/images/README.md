# Documentation image provenance

`crisp-fct-tidyplates-preview.png` was supplied explicitly for use as public project documentation. The release builder may copy this reviewed repository asset, but no tool captures or discovers screenshots from a game client.

Before any new screenshot is added here, a human must review the full image for chat, player and character names, realm or account details, guild information, calendar entries, private messages, and other identifying UI state. Record that review in the pull request.
