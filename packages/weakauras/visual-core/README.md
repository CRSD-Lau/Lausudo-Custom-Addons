# Lausudo Visual Core

This package contains one newly authored, visual-only WeakAura: **Lausudo Combat Focus Ring**. It uses a built-in Blizzard texture and a short reviewed trigger that shows the ring only while the player is in combat.

No Wago, Felbite, NaowhUI, SavedVariables, profile export, character mapping, or third-party import string is included.

Install `LausudoVisualCore` under `Interface\AddOns`, enable it with WeakAuras, and run:

```text
/lausudowa install
```

Installation is explicit. If another aura already owns the proposed name, the addon chooses a new name or refuses to overwrite it.
