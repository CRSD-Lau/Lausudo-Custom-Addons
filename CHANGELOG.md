# Changelog

## 2.0.0-alpha.1 — Lausudo Suite preview

- Rebuild the public project around a modular suite while preserving its existing repository URL and 1.x release history.
- Add a suite hub, opt-in local visual profiles, per-character profile tracking, and restore commands.
- Adapt group bubbles, paladin raid range, and tank target colors for optional public use. Remove fixed character/realm checks and the private bubble-font dependency.
- Preserve the existing combat text, nameplates, and permitted font packages.
- Add a module catalog, dependency-aware ZIPs, direct-to-archive builds, manifests, checksums, public-path checks, Lua 5.1 tests, and CI.
- Separate public sharing, client enhancement guidance, and exact private recovery. Never include LoginUI.
- New runtime behavior remains a preview pending the documented in-game acceptance checks. Exact owner-layout export and automated updates are not included.

## 1.x

Earlier addon and font releases remain in the repository's release history. Their original tags and assets are preserved.
